# Deny patterns — build-time only. Not included in the published JSON and never
# shipped to a browser. This file is public, like the rest of the repo, and that
# is intentional: it contains only well-known service domains, no user data, and
# it is not a security boundary. The runtime is default-deny, so what gets
# through is decided by the allowlist alone. Publishing what we filter is
# auditable, and PRs adding providers we have missed are welcome.
#
# Its only job is to fail the build if one of these ends up in
# allowed-referrers.txt. Each line is suffix-matched: an entry matches if it
# equals the pattern or is a subdomain of it.
#
# IP literals are NOT listed here. They can't be expressed usefully as suffix
# patterns (2130706433 and 0x7f000001 are both 127.0.0.1), so they are rejected
# in code by classifyEntry() in config/referrers.js — every IPv4 and IPv6 form,
# private and public alike.
#
# Rule of thumb for adding here: any domain where individuals get their own
# hostname pointing at a private network. Note this is a narrower test than
# "individuals get their own subdomain" — GitHub Pages does that too, but it
# serves published websites, not people's houses.
