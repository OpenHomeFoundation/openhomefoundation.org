# Allowed referrers — PUBLIC. Published as openhomefoundation.org/allowed-referrers.json
# and consumed by every Open Home Foundation site that runs Plausible.
#
# WHY THIS EXISTS
# Someone reaching one of our sites from their own Home Assistant or ESPHome
# instance sends their private URL as the referrer — a Nabu Casa Cloud address,
# a dynamic DNS hostname, or their own domain. We can't fix that at source
# (not everyone updates, and not every link carries rel="noreferrer"), so any
# referrer that isn't on this list is replaced with https://unlisted.invalid/
# before Plausible records it.
#
# HOW IT WORKS
# One domain per line. Each entry matches that domain AND all of its subdomains,
# so "reddit.com" covers "old.reddit.com" and "www.reddit.com". Blank lines and
# anything after a "#" are ignored. There is no other syntax — no wildcards, no
# regex, no exact-host mode.
#
# THE ONE RULE FOR ADDING SOMETHING
#
#   Only add a domain you recognise as a public website.
#
# This list is default-deny, and the two mistakes are not equally bad. Leaving a
# real site out costs one unused data point. Putting the wrong thing in publishes
# a real person's home URL — permanently, because this file is public and ends up
# in git history, on a CDN, and in the Internet Archive. So be generous with
# things you recognise and ruthless with things you don't.
#
# Never add: IP addresses in any form, hosts with port numbers, dynamic DNS
# providers, tunnels, or NAS/router remote access domains. The build rejects all
# of these automatically — see list/deny-patterns.txt and config/referrers.js.
#
# This is a starting list, not a complete one. It grows by PR.
